Links por tag

Marque uma ou mais tags e copie o link. Quem abrir vê o portfólio com só os projetos daquela seleção.

Tags dos projetos

Marque as tags de cada projeto, crie tags novas ou mude o nome das que já existem. Os filtros do portfólio usam exatamente o que estiver aqui.

Como salvar
  1. Faça as mudanças na tabela.
  2. Clique em Baixar arquivo. Vai baixar o projetos.json.
  3. Abra a pasta data do repositório no GitHub, clique em Add file › Upload files, solte o arquivo e confirme em Commit changes.
  4. Em um ou dois minutos o portfólio já mostra as tags novas.
